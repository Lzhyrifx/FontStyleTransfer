# FontStyleTransfer

本项目源自[FontDiffuser](https://github.com/yeungchenwa/FontDiffuser)<BR>
该项目探索修改FontDiffuser以生成完整手写字体的方法。<br>
我们允许模型从目标分布的多个样本中推断出样式,批量生成字体图像,最后转换为字体文件<br>
同时在优化目标字推理速度
